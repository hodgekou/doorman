# Changelog

## [0.1.2] - 2026-11-28

- Doorman now checks daily for signed updates. Choose **Check for Updates…** in the menu for a manual check, or turn off daily checks in General settings.
- If you use 0.1.1 or earlier, run the installer again or install the DMG once to receive future updates in the app.
- The command-line installer verifies the replacement before moving the old app and restores the old copy if replacement fails.
- Opening Doorman now clears expired entries from the lock history file. The project is available under the MIT license.

## [0.1.1] - 2026-11-27

- Fixed: Doorman 0.1.0 crashed right after launch on some Macs while requesting notification permission. Please update.
- Releases are now launch-tested before they're published.

## [0.1.0] - 2026-11-27

First public release.

- Locks your Mac when the Apple Watch or iPhone you carry moves away.
- Never locks while you're using the keyboard, mouse or trackpad; a 5-second countdown you can cancel comes first.
- Unlocking is left to macOS (Apple Watch Unlock, Touch ID or password). Doorman never stores or types your password.
- Live signal chart, sensitivity presets (Sensitive / Balanced / Relaxed), pause, and lock now from the menu bar.
- First-run guide, local lock history, and diagnostics.
- English, Simplified Chinese and Japanese, switchable in the app.
- One-command installer and a drag-to-Applications DMG for Apple silicon and Intel Macs.
